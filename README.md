# بيت التكنولوجيا | Tech House (Flask)

موقع معرض منتجات وخدمات تقنية بإشراف م. أحمد خميس (مهندس ميكاترونكس)، مع لوحة إدارة مخفية ونظام صلاحيات.

## التشغيل

```bash
python -m venv venv
source venv/bin/activate        # على ويندوز: venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

افتح http://localhost:5000

## أول مرة: حساب المدير

في قاعدة بيانات جديدة، افتح `/admin/setup` وأنشئ اسم المستخدم وكلمة مرور من 12 حرفاً على الأقل. عيّن `SETUP_KEY` قبل النشر لتقييد الإعداد الأولي. الحساب يخزن بكلمة مرور مجزأة باستخدام Werkzeug؛ لا توجد كلمة مرور افتراضية. إذا لم توجد بيانات حساب في قاعدة قديمة، أكمل الإعداد مرة واحدة.

## الدخول المخفي

- لا يوجد أي رابط للإدارة في الهيدر أو الفوتر.
- المسار: `/admin`، أو **5 ضغطات متتالية** على سطر الحقوق في آخر الصفحة.
- بعد 5 محاولات دخول فاشلة من عنوان الشبكة يتوقف الدخول 10 دقائق (التحديد داخل ذاكرة كل عملية).
- يمكن للمدير تغيير كلمة المرور من لوحة المتجر بعد تسجيل الدخول؛ تغييرها ينهي الجلسة الحالية.

## الصلاحيات

- **المدير العام** (أنت): كل شيء، وحده يدير المشرفين والصلاحيات ولا يمكن حذفه.
- لكل مشرف صلاحيات: عرض / إضافة / تعديل / حذف. أدوار جاهزة: مدير، محرر، مشاهد، أو تخصيص يدوي.
- قسم «المشرفون» غير ظاهر لغير المدير العام، وفتح رابطه يعطيهم 404 وكأنه غير موجود.
- أزرار الإضافة والتعديل والحذف لا تظهر إلا لمن يملك الصلاحية، والسيرفر يتحقق منها في كل طلب.

## النشر

```bash
gunicorn -w 2 -b 0.0.0.0:8000 app:app
```

اضبط `SECRET_KEY` بقيمة عشوائية ثابتة، و`PUBLIC_BASE_URL` بعنوان الموقع العام (مثل `https://example.com`)، و`SESSION_COOKIE_SECURE=1` عند استخدام HTTPS. يمكن استخدام `SETUP_KEY` لحماية التهيئة الأولى، و`DATABASE_PATH` لتحديد قاعدة البيانات. لا تترك `ADMIN_PASSWORD` القديم مضبوطاً؛ لا يقبل ترحيله إلا إذا كان طوله 12 حرفاً على الأقل.

**تنبيه Vercel:** لا يوجد إعداد Vercel أو تخزين دائم ضمن ملفات المشروع الحالية. قاعدة SQLite الافتراضية في `/tmp` والرفع إلى القرص المؤقت غير دائمين في بيئات serverless. قبل النشر هناك، اربط قاعدة بيانات دائمة عبر `DATABASE_PATH`/طبقة قاعدة بيانات مناسبة، وخزّن الصور في خدمة ملفات عامة دائمة مع `UPLOADS_PATH` دائم أو استخدم روابط صور HTTPS عامة. التطبيق يرفض الصور المرفوعة كـ data URL على Vercel إذا لم يضبط `UPLOADS_PATH` بدلاً من حفظها المؤقت.

بعد النشر، افتح [Facebook Sharing Debugger](https://developers.facebook.com/tools/debug/)، أدخل رابط `/product/<id>` واضغط **Debug** ثم **Scrape Again** لتحديث نسخة المعاينة المخبأة.

## الهيكل

| الملف | الوظيفة |
|---|---|
| `app.py` | المسارات، SQLite، المستخدمون والصلاحيات، رفع الصور |
| `templates/` | قوالب Jinja2 (المتجر، الإدارة، الأيقونات) |
| `static/style.css` | التصميم (RTL) |
| `static/app.js`, `static/admin.js` | فلترة المنتجات، الدخول المخفي، نموذج الصلاحيات |
| `instance/` | قاعدة البيانات والصور المرفوعة (تُنشأ تلقائياً) |
